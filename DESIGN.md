## Executive Summary & Strategic Pivot

CiteAssist AI is pivoting from a local Tauri desktop application (aimed at enterprise research lab sales) into a direct-to-consumer, web-first academic SaaS priced at **$49/year (or $29 single-paper emergency pass)**. The product functions as the "pre-flight checklist" for PhD students, postdocs, and academic researchers to eliminate peer-review desk rejections caused by hallucinated citations, dead DOIs, retracted papers, and missing literature baselines before submitting to high-stakes venues (NeurIPS, ICML, CVPR, Nature, IEEE, ACM, Elsevier).

---

## Problem Statement

Academic publishing operates on brutal 6-to-12 month review cycles where a single mechanical or citation flaw leads to immediate desk rejection by journal editors or brutal disqualification by Reviewer #2. 

Today, researchers face three existential pre-submission risks:
1. **The LLM Hallucination Trap**: Researchers using ChatGPT, Claude, or Copilot to draft literature reviews inadvertently inherit fabricated DOIs, phantom co-authors, and misattributed findings that reviewers easily identify.
2. **Retraction & Citation Rot**: Over 10,000+ scientific papers are retracted annually. Citing a retracted or debunked paper can trigger editorial desk rejection and severe reputation damage.
3. **The 2 AM Submission Panic**: Right before conference deadlines (11:59 PM AoE), researchers manually cross-reference 50–120 in-text citations against messy `.bib` files, hunting down missing reference keys, mismatched years, syntax errors, and broken DOIs.

## Status Quo & The Competitor Landscape

### Current Workarounds
Researchers currently duct-tape together 4 disjointed tools with zero integrated pre-flight audit score:
- **Zotero / Mendeley**: Great for static reference storage, but zero proactive detection of AI hallucinations, retracted papers, or claim-evidence mismatch.
- **Grammarly / Paperpal**: Focus on prose styling, spelling, and ESL grammar, but blind to citation integrity, benchmark completeness, or BibTeX parsing bugs.
- **Scite.ai**: Analyzes citation context/sentiment, but costs $144–$240/yr (prohibitive for student out-of-pocket spend) and does not offer 1-click BibTeX file repair.
- **Manual 2 AM Check**: 4 to 8 hours spent cross-referencing Google Scholar, CrossRef, and LaTeX logs by hand under extreme stress.

## Target User & Narrowest Wedge

### The Desperate Persona
- **Primary User**: "Alex", a 3rd/4th-year PhD Candidate or Postdoc in Computer Science, Biomedicine, or Quantitative Social Science submitting a first-author paper.
- **What gets them promoted**: Getting accepted into top-tier peer-reviewed conferences/journals.
- **What keeps them up at night**: The nightmare of a desk rejection due to a stupid citation mistake or citing a retracted paper that invalidates their literature review.

### The Narrowest Wedge: "Instant Pre-Flight Scorecard"
A zero-barrier, drag-and-drop web scanner where a researcher drops their `.tex`, `.bib`, or `.pdf` file without logging in, and within 15 seconds receives an interactive **Peer Review Submission Health Report**:
- **Desk-Rejection Risk Score** (e.g., `88/100 — 3 Critical Red Flags Detected`)
- **Retracted Paper Warnings** (Cross-referenced against RetractionWatch/OpenAlex)
- **Dead / Fabricated DOI Alerts** (Validating all DOIs against CrossRef)
- **BibTeX Mismatch & Orphan Citations** (Citations in text missing from `.bib`, or references never cited)
- **Missing Seminal Baselines** (Flagging top 3 missing papers frequently co-cited in this exact subfield)

2. **The Freemium Hook**: Revealing red flags (retractions, broken DOIs, missing baselines) for free creates high urgency; gating 1-click automated repairs and deep claim-evidence diffs behind Pro maximizes conversion.

## Approaches Considered

### Approach A: Standalone Next.js Web SaaS (Selected)
- **Summary**: Migrate the core React UI into a modern Next.js web app. Features client-side IndexedDB local persistence for zero-friction drag-and-drop file processing, serverless API routes for CrossRef/OpenAlex/Semantic Scholar validation, and Stripe Checkout.
- **Effort**: Small (Human: ~1-2 weeks / CC: ~30 min)
- **Risk**: Low
- **Pros**:
  - Reuses 90%+ of existing React audit table, status bar, and settings components.
  - Zero cold-start friction: users can drag and drop without immediate account creation.
  - Instant global reach and frictionless Stripe billing.
- **Cons**:
  - Requires web API routes for citation metadata fetching (replacing Rust desktop IPC).
- **Reuses**: Existing React state management, citation classification logic, and AST parsers.

### Approach B: Full-Stack Cloud Workspace with Live Supabase Sync
- **Summary**: Full multi-tenant SaaS with PostgreSQL/Supabase, project history, live team editing, and distributed worker queues.
- **Effort**: Large (Human: ~4-6 weeks / CC: ~2-3 hours)
- **Risk**: Medium
- **Pros**:
  - Enables long-term cloud storage and team-level lab collaboration.
- **Cons**:
  - Unnecessary infrastructure overhead before validating willingness to pay; creates signup friction for first-time visitors.

### Approach C: Overleaf Chrome Extension + Cloud API
- **Summary**: Lightweight browser extension that overlays an interactive citation pre-flight bar inside Overleaf.com.
- **Effort**: Medium (Human: ~2-3 weeks / CC: ~1 hour)
- **Risk**: Medium
- **Pros**:
  - Lives directly inside the researcher's daily writing environment.
- **Cons**:
  - Dependent on Chrome Store review process and Overleaf DOM structure. Best positioned as a Phase 2 growth amplifier after the web SaaS is live.

## Recommended Approach & Implementation Roadmap

### Phase 1: Zero-Friction Web Pre-Flight App (Launch MVP)
1. **Frontend Architecture**: Standalone Next.js app preserving the 3-pane workbench (File Tree, CodeMirror LaTeX Editor, Audit & Red Flag Diagnostic Panel).
2. **Zero Cold-Start Workspace**: Client-side IndexedDB storage allows instantaneous drag-and-drop of `.tex` and `.bib` files with zero signup wall.
3. **API Engine**:
   - `POST /api/audit/preflight`: Parses LaTeX/BibTeX, extracts citations, checks DOIs via CrossRef & OpenAlex, queries RetractionWatch.
   - `POST /api/audit/claim-check`: Deep semantic comparison of cited text claims against literature abstracts using fast LLM inference (Groq/OpenAI).
4. **Stripe Monetization**:
   - Stripe Checkout for $49/yr Annual Pro & $29 Emergency Pass.
   - Webhook handler for instant Pro token generation and entitlement unlocking.
5. **Shareable Audit Certificate**:
   - `GET /report/[id]`: Public read-only submission certificate for co-author review.

### Phase 2: Growth Amplifiers (Post-Revenue)
- Overleaf Chrome Extension integrating directly with the `/api/audit` endpoints.
- 1-Click Zotero / Mendeley cloud library import.

## Open Questions & Risk Mitigations

1. **API Rate Limiting on Free Scans**:
   - *Mitigation*: Cache all DOI and CrossRef/OpenAlex query results in Redis/Edge cache. 80% of citations in a given field overlap across papers.
2. **File Privacy & Academic Leak Anxiety**:
   - *Mitigation*: Emphasize client-side LaTeX parsing where only citation keys and DOIs are queried against public databases; no unpublished manuscript text is stored on servers without permission.
