## Affected Pages & API Routes
- `/` — Core 3-pane workbench (Drag-and-drop file ingestion, virtual tree, CodeMirror editor, pre-flight score card)
- `/api/audit/deterministic` — Deterministic BibTeX syntax, CrossRef DOI check, Retraction Radar, Orphan detection

- `/api/stripe/webhook` — Stripe checkout & subscription lifecycle listener
- `/api/stripe/claim-session` — Immediate Pro token retrieval upon return from checkout

## Critical Paths & User Flows
1. **Zero Cold-Start Drop**: User lands on web app with no account -> drags `sample.tex` + `references.bib` -> instant pre-flight scan displays within 15 seconds.
2. **Tab Reload Recovery**: User refreshes browser -> `autoRestoreSession` pulls state from `idb-keyval` without data loss.
3. **Upgrade & Unlock**: User clicks "Unlock 1-Click Fixes" -> completes Stripe checkout -> returns with session ID -> Pro token claims immediately and unlocks `/api/audit/entailment`.
